System Architecture & Physical Parity (MoES PS 26077)

Problem Statement Alignment

Problem Statement 26077 (Ministry of Earth Sciences) requires hyper-local early warning for cloudbursts and flash floods with 2–6 hours advance lead time. Conventional radar and numerical weather prediction (NWP) fail in complex Himalayan terrain due to beam blockage and coarse 12km grid resolution.

1. SNN Neuromorphic Precursor Gate

A Leaky Integrate-and-Fire (LIF) neuron runs on micro-power edge hardware. It remains dormant during nominal conditions (saving 91.4% power) and fires an instant edge wake-up alert only when rapid rain intensification is detected.

2. 1D-CNN + BiLSTM Neural Nowcaster

Standardized features pass through a 1D temporal convolution followed by bidirectional LSTM and class head. Validated on historical IMD AWS datasets achieving CSI = 0.4154, POD = 88.75% at the 15% operational alert threshold.

3. Tier-2 Spatial Confirmation Gate

Computes the Spatial Localization Index L = (R_core − R_bg) / max(R_core, 1) against surrounding AWS stations within a 50 km radius. If rain is uniform across all stations, false alarms are suppressed.

4. PINN 2D SWE Flash Flood Hydrodynamic Inundation

Simulates dynamic riverbed flood torrents and backwater pooling at valley bottlenecks (Sonprayag, Tapovan, Maneri).
